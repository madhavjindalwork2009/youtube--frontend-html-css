# YouTube Homepage Clone 📺

Welcome to my YouTube Homepage Clone! This is a responsive, pixel-perfect frontend clone of the YouTube web interface. 

I built this project entirely from scratch on my own to deeply practice and master modern web development techniques without relying on AI tools. 

## ✨ Features
* **Modern Layouts:** Heavy utilization of CSS Grid and Flexbox to create the complex video grid and navigation bars.
* **Fully Responsive:** Custom media queries ensure the layout adapts beautifully across desktop, tablet, and mobile screens.
* **Interactive Elements:** Features custom CSS tooltips, hover states, and layered z-index positioning for the fixed header and sidebar.
* **Clean Architecture:** CSS is modularized into separate files (header, sidebar, video grid, and general styles) for highly maintainable code.

## 🛠️ Tech Stack
* **HTML5:** Semantic markup for structured and accessible content.
* **CSS3:** Advanced styling, animations, and responsive design.

## 📂 Project Structure
```text
